## 📷 **프로젝트 개요**
### 🔹 WhaleWatch란?
가상화폐 시장에서 '고래'라 불리는 대형 투자자들의 거래를 실시간으로 추적하고 텔래그램 알림을 받을 수 있는 서비스입니다. 대규모 거래는 종종 시장 가격에 영향을 미치기 때문에, 이를 빠르게 파악하여 투자 결정에 활용할 수 있습니다.

### 🔹 개발 동기
가상화폐 시장에서 정보의 비대칭성은 투자 결정에 큰 영향을 미칩니다. 특히 대형 투자자들의 움직임은 시장 전체에 파급 효과를 가져오는데, 이러한 정보에 빠르게 접근하기 어려운 일반 투자자들을 위해 WhaleWatch를 개발하게 되었습니다. 복잡한 데이터를 처리하고 의미 있는、실행 가능한 정보로 변환하는 프로세스를 자동화하여 사용자에게 가치를 제공하고자 했습니다.

## 시스템 아키텍처

### 🔹 기술 설계
WhaleWatch는 마이크로서비스 아키텍처를 채택하여 각 서비스가 독립적으로 개발, 배포, 확장될 수 있도록 설계되었습니다. 이벤트 기반 아키텍처를 통해 시스템 컴포넌트 간 결합도를 낮추고, 실시간 데이터 처리를 가능하게 했습니다.

### 🔹 주요 목표 및 특징
- **실시간 데이터 처리**: Kafka와 Spring Cloud Stream을 활용한 스트리밍 데이터 처리 시스템 구현
- **확장성 높은 인프라**: Docker와 마이크로서비스 아키텍처로 수평적 확장 가능한 시스템 구축
- **고가용성 설계**: 중요 데이터는 Redis 캐싱을 통해 빠른 응답 속도 보장
- **API 기반 통합**: RESTful API와 이벤트 기반 통신으로 서비스 간 효율적인 데이터 교환
- **보안 강화**: Spring Security와 JWT를 활용한 안전한 사용자 인증 체계 구현
- **사용자 친화적 인터페이스**: 텔레그램 봇을 통한 직관적인 알림 시스템 구현

## ⚙️ **주요 기능 상세**
### 📌 **1. 사용자 인증 및 관리 시스템**
- **JWT 기반 인증**: 안전한 토큰 기반 인증 시스템 구현
- **역할 기반 접근 제어**: 사용자별 권한 관리 및 접근 제어
- **사용자 프로필 관리**: 개인화된 설정 및 정보 관리
- **텔레그램 계정 연동**: OAuth를 통한 외부 서비스 연동

### 📌 **2. 트랜잭션 모니터링 시스템**
- **멀티 거래소 API 통합**: 주요 가상화폐 거래소 API 연동 및 데이터 수집
- **대규모 거래 감지 알고리즘**: 실시간 데이터 스트림에서 의미 있는 거래 탐지
- **패턴 인식 및 분석**: 과거 데이터 기반 이상 거래 패턴 인식
- **데이터 필터링 및 가공**: 사용자 설정에 따른 맞춤형 데이터 필터링

### 📌 **3. 실시간 알림 시스템**
- **텔레그램 봇 인터페이스**: 사용자 친화적인 메시지 형식 및 명령어 구조
- **알림 우선순위 설정**: 중요도에 따른 알림 분류 및 전송
- **맞춤형 알림 설정**: 코인 종류, 거래량 임계값, 시간대별 설정 가능
- **알림 히스토리 및 분석**: 과거 알림 이력 조회 및 통계 제공

### 📌 **4. 커뮤니티 및 정보 공유 시스템**
- **실시간 댓글 및 토론**: 특정 거래나 코인에 대한 사용자 간 의견 교환
- **인사이트 공유**: 분석 결과 및 해석 공유 기능
- **뉴스 및 정보 통합**: 관련 뉴스와 시장 정보 통합 제공

### 🔹 서비스 간 통신 흐름
1. **Collector Service**에서 거래소 API를 통해 실시간 거래 데이터 수집
2. 수집된 데이터는 Kafka 토픽으로 전송되어 이벤트 스트리밍
3. **Transaction Service**에서 데이터를 소비하여 분석 및 필터링
4. 중요 거래 감지 시 알림 이벤트 생성 및 Kafka로 전송
5. **Notification Service**에서 알림 이벤트 소비 및 텔레그램 메시지 전송
6. **User Service**를 통해 사용자별 알림 설정 및 권한 관리
7. **Post Service**를 통해 커뮤니티 기능 제공 및 사용자 인사이트 공유
